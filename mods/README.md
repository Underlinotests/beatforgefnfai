# Instalação de mods

- `_template/` contém um projeto base **não instalado**. Copie-o e renomeie conforme as instruções em `_template/README.md`.
- Um mod só é carregado quando a pasta contém um `mod.json` válido com `id` idêntico ao nome da pasta.
- Os mods de jogadores também podem ser instalados em `user://mods/` através do menu MODS.
